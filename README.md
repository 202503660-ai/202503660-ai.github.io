# TROIKA 방문객 가이드 — 데이터 사용 내역

세 대학 주변에서 취향에 맞는 골목을 찾고, 제안 코스를 살펴보고, 가상 스탬프·쿠폰을 체험하는 행사 가이드입니다. 제공 자료 10종을 검토한 뒤 방문객 기능에 필요한 CSV 3종만 앱 데이터에 포함했습니다. 원본 CSV 10개와 노트북은 수정하거나 삭제하지 않았습니다.

## 현재 사용하는 자료

| 제공 파일 | 사용 항목 | 쓰임 |
| --- | --- | --- |
| 서울시 상권분석서비스(영역-상권).csv | 상권 코드·이름·유형·행정동·면적·중심 좌표 | 23개 상권 연결, 지도, 직선 거리, 상세 정보 |
| 서울시 상권분석서비스(점포-상권).csv | 업종 코드·이름·전체 점포 수 | 음식·카페 업종 구성에 따른 추천, 업종별 점포 수 |
| 서울시 상권분석서비스(길단위인구-상권).csv | 상권 코드·6개 시간대 유동인구 값 | 시간대별 분포 표시. 실시간 혼잡도로 해석하지 않음 |
| troika_stamp_analysis.ipynb | 대상 23개 상권 코드, 회기·이문·전농 권역, 테마·코스·스탬프 배정안 | 행사 기획. 수기 매출·좌표·경제효과는 사실값으로 쓰지 않음 |
| .superdesign/original-index.html 및 original-styles.css | 원본 화면 구성·브랜드 | TROIKA 워드마크, 취향 선택·지도·코스·스탬프 흐름 참고 |

CSV의 최신 공통 분기는 **2026년 2분기**입니다. 대상 상권은 **23곳**, 해당 업종 집계 점포 합계는 **4,374곳**입니다. 이는 개별 제휴 매장 수가 아닙니다. CSV는 CP949로 읽고 상권 코드로 연결하며, 중복 키를 검사합니다. 일반·프랜차이즈 수를 전체 점포 수에 재가산하지 않습니다. 전체 점포 합계는 규모 참고용으로 유지하며, 앱에 담는 업종별 목록은 음식·카페·장보기·의류·서적·문구·화초 등 탐방 관련 업종으로 제한합니다. 병원·교육·부동산 등은 상세 목록에서 제외하므로 목록의 합은 전체 점포 수와 다릅니다.

| CSV 구분 | 제외 이유 |

| 집객시설-상권 | 시설 총수만으로 공연·체험 장소나 방문 편의시설을 확인할 수 없음 |
| 상권변화지표-상권 | 개·폐업 및 운영 기간 등 상권 진단 지표는 방문객 화면에 불필요 |
| 점포-상권배후지 | 상권 점포와 공간이 중복될 수 있어 합산하지 않음 |

위 7종은 데이터 생성 과정에서 읽지 않으며 data.js에도 포함하지 않습니다. 매출·성장성·정책필요도 등을 사용하던 기존 기본지수도 제거했습니다. 원본 파일은 향후 운영자 분석용으로 보존했습니다.

## 추천과 표시 기준

퀴즈는 권역, 주목적, 세부 관심사, 동행, 탐방 방식, 거리 선호의 6문항입니다. 마지막 답변에서만 적용하며 중간에 닫으면 기존 취향을 유지합니다. 다시 열면 현재 답변을 표시하고, 이전 질문으로 돌아가 수정할 수 있습니다. 취향 초기화는 세부 응답도 초기화합니다.

선택 권역 안에서 주목적45·거리20·세부관심20·동행10·탐방방식5의 가중치를 사용하고, ‘모르겠어요/상관없음’ 응답 항목은 분모에서도 제외해 100점으로 환산합니다. 공식 서울시 순위가 아닌 자체 탐방 추천입니다.

상권 컨셉은 한 끼(한식·분식), 세계 음식(중식·일식·양식), 커피, 빵집, 시장·장보기, 쇼핑, 저녁 모임(주점), 문화·교류로 구성합니다. 업종 점수는 sqrt(해당 점포/전체 점포 × 4)를 최대1로 제한합니다. 전통시장의 시장 컨셉은1, 문화 컨셉은 노트북 테마·코어 기획을 사용합니다. 카드와 상세에서 최대3개 컨셉을 보여주며, 관심 컨셉에 해당 업종이 없다면 태그로 표시하지 않습니다.

동행은 혼자→한 끼·커피, 친구→세계 음식·주점·문화, 둘이서→커피·빵집·쇼핑, 가족→한 끼·시장이라는 편집상 제안입니다. 가족 편의시설·좌석·안전·정숙성 인증이 아닙니다. 집중 탐방은 가장 강한 업종 컨셉, 다양한 탐방은 7개 업종 컨셉 평균을 반영합니다. 거리 점수는 기존 권역 중심 직선거리 기준을 유지합니다. 가상 혼잡도는 순위에 반영하지 않습니다.

지도는 EPSG:5181 좌표를 EPSG:4326으로 변환한 상권 중심점입니다. 이름·행정동·면적·좌표는 노트북보다 CSV를 우선합니다. ‘전농2동 일대’는 최신 공식 이름 ‘텃골근린공원’으로 표시합니다.

시간대별 분포는 길이가 다른 여섯 구간의 원자료 구성비입니다. 실시간 동시 인원·고유 방문자 수·혼잡도로 해석하지 않습니다. 시간 조절은 표시만 변경하며 추천 순위에는 반영하지 않습니다.

## 가상 체험

사용자 요청으로 가상 혼잡도와 쿠폰을 유지합니다. 가상 혼잡도는 시간 구간별 기본값 [18,32,65,48,76,39]에 상권 코드 끝 두 자리 % 21을 더하고 최대 95로 제한합니다. 45 미만 여유, 75 미만 붐빔, 그 이상 혼잡입니다. 실제 통계와 독립적인 임의의 시나리오이며 실측·예측 수용률이 아닙니다.

가상 스탬프는 서로 다른 상권 3곳에서 모으며, 완료 시 실제 사용이 불가능한 15% 체험 쿠폰을 표시합니다. 탐방 목록과 가상 체험은 별도 브라우저 저장 키를 사용하고 각각 초기화할 수 있습니다.

스탬프 배정은 B10-14(2026-09-13) PDF 7–8쪽의 최종 결과를 반영했습니다. 대상 16곳·2,699점포, 총 60개로 코어36/참여24/연계0입니다. 상권별 최소2개, 최대 min(6, floor(점포수×0.2))를 지킵니다. 확정 가맹점 수가 아닙니다.

D·L·R·M은 PDF의 소수 셋째 자리 공개값을 저장한 고정 결과입니다. 거리 원자료 재계산이 아닙니다. 이경시장 매출은 2026년 1분기 대체값입니다. 최신 연계존 교정 명단이 없어 기존 전체23곳·4,374점포를 유지합니다. 취향 추천과 정책 지수는 독립적이며 상세 화면에서 배정 근거를 확인합니다. `tools/apply_final_allocation.py`를 데이터 생성 시 적용해 최종 배정을 보존합니다.

## 실행·재생성·검증

- 미리보기: `node tools/serve.cjs` → http://127.0.0.1:4173/
- 테스트: `node --test tests/core.test.cjs tests/allocation.test.cjs`
- 재생성: pandas·pyproj가 있는 Python에서 `python tools/build_data.py`
- 앱은 생성된 data.js를 사용하므로 실행에 Python이 필요하지 않습니다.
- 실제 사용 CSV 3개별 행수·최신 분기·SHA256 및 노트북 SHA256을 data.js에 기록합니다.
- 노트북 전체를 실행하지 않고 AST로 필요한 기획 리터럴만 읽습니다.
