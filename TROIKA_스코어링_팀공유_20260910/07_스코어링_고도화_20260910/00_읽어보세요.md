- 기존 입력 CSV에서 점수·민감도 독립 재현.
- 문서와 코드의 차이 및 공식 지표 정의 오류 확인.

새 산식의 실데이터 최종 순위나 참여 확정 점포 명단은 아닙니다. 실제 보행시간, 기간을 맞춘 원자료, 점포 참여·운영·안전 확인 후 다음 구현을 진행합니다. 원본 `06_스코어링` 파일은 변경하지 않았습니다.

## 검증 재실행

검증 코드는 `검증/audit_scoring.py`입니다. 공유 문서만 읽는 데는 실행 환경이 필요 없습니다.

재실행하려면 원래 폴더 구조에서 이 패키지와 `06_스코어링`을 같은 부모 폴더에 두세요. `06_스코어링`의 `out6_indicators.csv`, `out6_scores.csv`, `score_v2.py`, `score_v3.py`, `team_data.xlsx`가 필요합니다. 압축본에는 기존 팀 원본을 중복 포함하지 않았습니다.

```text
python -X utf8 검증/audit_scoring.py
```

의존성: pandas, numpy, Excel 읽기 엔진(openpyxl). 원본을 수정하지 않고 검증 결과와 입력 해시를 출력합니다.
