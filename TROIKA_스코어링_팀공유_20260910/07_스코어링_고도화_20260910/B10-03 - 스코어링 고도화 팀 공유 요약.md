# 스탬프 제휴 스코어링 고도화 — 팀 공유 요약

## 이번 회의에서 합의할 결론

**지원 필요성으로 우선순위를 정하되, 안전하고 운영 가능한 점포만 선정한다. 상권 점수와 개별 점포·동선 선정을 분리한다.**

기존 2026-09-09 결과는 계산식대로 재현됐다. 다만 입력 지표의 의미와 문서·코드가 일부 달라 **기존 순위를 최종 제휴 명단으로 사용하면 안 된다.** 이번 작업은 그 차이를 검증하고, 구현 가능한 다음 설계를 정의한 것이다. 새 설계의 실데이터 최종 순위·확정 점포 명단을 산출한 것은 아니다.

검토 범위: 옵시디언 B9-00, B10-00~02, 공유 폴더의 `score_v2.py`, `score_v3.py`, 지표·점수 CSV, 팀 진단 파일. 노션 내용은 B10에 보존된 9월 9일 정리본을 기준으로 했으며, 이번 작업에서 노션 원문을 다시 열람하거나 수정하지 않았다.

## 1. 유지할 것과 바꿀 것

| 항목 | 유지 | 고도화 제안 |
|---|---|---|
| 대상 범위 | B9의 코어·참여존에 속한 상권 16곳 | 상권 통계상 점포 2,393개와 실제 경계 안 제휴 가능 점포 수를 구별 |
| 정책 목적 | 인기 순위와 구분되는 지원 우선순위 | 지원 필요성 N과 도달 가능성 A를 함께 보고 개입 유형 구분 |
| 2단계 구조 | 상권 진단 후 점포 선정 | 상권 점수 → 안전·운영 확인 → 중복 없는 점포·동선 묶음 |
| 안전 S | 중요한 평가 차원 | 다른 점수로 상쇄할 수 없는 필수 통과 조건 |
| 실행 가능성 F | 운영 준비가 중요 | 상인회 유무 대신 참여 동의·영업시간·수용력 확인. 미확인은 보류 |
| 가중치 | 민감도 비교 | 제안값임을 공개. 권역마다 다른 점수를 서로 비교하지 않음 |

권장 기본안:

```
사전 진단: Q_i = 0.50 N_i + 0.30 A_i + 0.20 √V_i

최종 선정 후보: 범위 적합 AND 참여 동의 AND 안전 확인 AND 운영 가능
선정: Q를 참고하여 권역 배분·예산·시간·수용력·동선 중복을 함께 제한
```

0.50 / 0.30 / 0.20은 연구에서 추정한 최적값이 아니라 **팀 합의를 위한 출발값**이다. 다섯 차원 V·A·S·N·F를 없애는 것이 아니라 S·F를 점수 합산에서 필수 확인 절차로 옮기는 제안이다. √V는 인기 보상의 증가폭을 줄이지만 상한에서 잘라내는 함수나 최소 집객 게이트는 아니다.

상세 산식·입력 계약·선정 규칙은 [[B10-04 - 스코어링 구현 설계서]].

## 2. 가장 먼저 수정해야 할 네 가지

1. **무대거리 기준**: 문서는 세 대학 무대 중 최단거리, 실제 코드는 경희대 앞 상권 한 곳과의 폴리곤 간 거리다. 서울시립대의 기존 무대거리 423.8m는 ‘자기 대학 무대까지 거리’가 아니다. 세 대학 실제 출입구·무대 후보와 보행경로를 명시해 다시 계산한다.
2. **서로 다른 지표의 혼합**: 팀 매출·유동 지수 없는 상권에는 별도 Z점수와 매출건수 밀도를 넣는다. 매출건수는 유동인구가 아니다. 전체 후보에 동일 정의를 적용하고 부족한 항목은 NA로 남긴다.
3. **안전 점수의 과해석**: 철도·간선도로에서 멀거나 야간 유동이 적다는 이유로 안전하다고 할 수 없다. 실제 접근·대기·비상 통로를 점검하고 미확인 점포는 최종 추천하지 않는다.
4. **상권변화지표 오기**: HH는 정체, HL은 상권축소, LH는 상권확장, LL은 다이나믹이다. 기준은 매출·점포 증가율이 아니라 생존·폐업 사업체의 평균 영업기간이다. 이 등급을 순서형 점수나 자동 가점으로 쓰지 않는다. [서울시 공식 정의](https://golmok.seoul.go.kr/policy/regionAnalysis.do)

전체 감사 결과와 수정 근거는 [[B10-05 - 기존 점수 검증과 참고자료]].

## 3. 검증에서 확인한 숫자

| 확인 항목 | 결과 | 팀이 말할 수 있는 범위 |
|---|---|---|
| 기존 16개 상권 점수 재계산 | 최대 차이 5.6×10⁻¹⁷ | 저장된 점수와 산식은 일치 |
| 유동 관측 보유 | 9/16곳 | 7곳의 값에는 결측·대체 문제 존재 |
| 기존 가중치 36조합 | 회기시장·경희대삼거리 Top5 36/36 | 해당 입력·변환을 고정한 가중치 비교에서 안정적 |
| N의 두 결측 항만 0~1로 변화 | 회기시장 1~4위, 회기역 1~13위 | 결측 가정에 따라 순위가 달라질 수 있음 |
| 기존 60곳 쿼터 합계 | 60 | 참여 동의·점포별 수용력을 확인한 60곳은 아님 |

순위 범위는 **확률이나 통계적 신뢰구간이 아닌 보수적 스트레스 범위**다. V·A·S의 오류까지 고친 결과가 아니므로 최종 안정성으로 해석하지 않는다.

## 5. 발표 자료에 바로 넣을 구성

“16개 상권을 정책 지원 필요성·보행 접근성·기초 활력으로 진단하고, 안전·운영 확인을 통과한 점포 중에서 권역과 동선의 균형을 고려해 선정합니다.”

**2장 — 왜 고도화했는가**  
단일 무대 기준의 편향, 7개 상권의 결측, 안전 프록시를 보여준다. 기존 점수 재현 결과와 N 결측 스트레스 범위를 나란히 놓는다.

**3장 — 실행·검증**  
상권 진단 → 현장 게이트 → 점포 묶음 선정 → 운영 중 추천 제한 → 방문·사용 로그 평가. 확인하지 않은 안전성, 소비 전환율, 축제 매출 효과를 확정 수치로 발표하지 않는다.
