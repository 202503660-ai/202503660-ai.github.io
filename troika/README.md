```powershell

```

## 스탬프 배정

`tools/scoring.py`가 CSV로부터 직접 계산한다.

- D: 20대 소비강도 변화·점포 증감·폐업률·전체 매출 변화의 백분위 평균을 다시 백분위화.
- L: 점포당 매출이 낮을수록 높은 백분위. 규모의 영향을 줄이는 대리지표.
- R: `exp(-1.189 * 거리_km)`. 기록된 기존 23개 상권의 평시 20대 유동 비중으로 추정한 계수. 축제 당일 효과 실측이 아니다.
- M: `sqrt(D * L) * R`.

`max Σ M_i sqrt(k_i)`를 총량60, 최소2, 최대6, 점포 수의20% 내림 상한 아래에서 푼다. 한계효과 순서대로 배정하며 동적계획법과 대조한다. 최소값보다 모집 상한이 작거나 총량을 채울 수 없는 입력은 오류로 알린다. 현재 16곳의 결과에는 영향이 없다.

연계존은 0개다. 영역 규칙상 전농119안전센터·전농1동주민센터를 제외하고 떡전교사거리·동대문경찰서를 포함한다. `build_data.py`가 명단 교정을 실제 적용하므로 재생성해도 되돌아가지 않는다.

## 자료와 해석

서울시 상권분석서비스의 영역-상권, 점포-상권, 길단위인구-상권, 추정매출-상권 **4종**을 사용한다. 각 CSV의 행 수·최근 분기·SHA256 및 노트북 SHA256을 `data.js`에 기록한다. 공통 최신 분기는 2026년 2분기다.

- 영역 CSV의 좌표는 EPSG:5181에서 EPSG:4326으로 변환한다. 지도는 상권 중심이며 개별 매장 입구가 아니다.
- 점포는 업종별 전체 점포 수를 합산한다. 일반·프랜차이즈 수를 재가산하지 않는다. 상세 업종 목록은 탐방 업종만 표시하므로 전체 합과 다를 수 있다.
- 매출 CSV는 배정 계산에 쓴다. 상세 화면과 `data.js`에는 D·L·R·M, 점포당 매출, 사용한 매출 분기를 담는다. 원자료의 업종별 매출 전체는 담지 않는다.
- 2021~2024년 집계 매출은 `tools/sales_history_pre2025.csv`로 보완한다. 기준은 2022년4분기, 점포 증감 기준은 2025년1분기다.
- 이경시장의 최신 매출 결측은 2026년1분기의 직전 유효 매출로 대체했다. `perStoreQuarter`와 화면에 대체 분기를 표시한다. D 구성 지표의 결측은 중앙값으로 처리한다.
- 20대 소비강도는 매출/유동 집계 비율이며 개인별 객단가가 아니다. 20대를 대학생으로 식별할 수 없다.
- 시간대는 `[6,5,3,3,4,3]`시간으로 나눠 정규화한 비중이다. 실시간 혼잡·고유 방문자·동시 인원 자료가 아니다.
- 가상 혼잡도와 15% 쿠폰은 데모이며 실제 방문 인증·할인 발급이 아니다. 배정60개는 확정 제휴 매장 수가 아니다.
